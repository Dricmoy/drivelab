# DriveLab — Technical Noir coherence

## Outcome

Warm semantic roles now apply to Replay, Evaluation, Dataset, Model, dialogs,
2D SVG and 3D materials. No cool-blue matches were found by the bounded computed
style audit of rendered text, backgrounds and top borders across the four modes
at eight actual browser widths. Existing dataset/checkpoint and recorded runs
were preserved. Local datasets and checkpoints are excluded from publication.

## Five concrete starting problems

1. Cyan sliders, selected paths and learned scores contradicted warm actions/type.
2. Legacy hover, help, modal, icon and border rules could leak a different theme.
3. The renderer separately used cyan ego paint, cool glass and purple inspection.
4. The outer document still inherited a light legacy background around dark UI.
5. Phone inspection was separated from evidence; one-scene percentages visually
   outweighed sample scope. Imagery and preparation guidance interrupted tasks.

## Two independent screenshot critiques

Round 1 reviewer saw only eight desktop/phone screenshots and the goals/brief.
Findings: decision/evidence separated, overlapping paths hard to connect to scores,
and import guidance too late. Fixes: playback-adjacent decision summary, inspector
before whole-run metrics on phones, stronger selected/dashed inspected paths,
dimmed candidate/lane noise, and inline format/path guidance before import.
Model controls now precede its photograph.

Round 2 reviewer likewise saw only eight updated screenshots and the brief.
Findings: phone scene too late, sample scope weaker than large percentages, and
engine-file location/training access unclear. Fixes: scene before playback and
decision summary; explicit recorded-scene/sample scope and collision counts;
"Evaluate all N scenes" action; engine-computer path explanation; working "New
training run" shortcut. Both reviewers found the warm visual system coherent.
The main agent then reviewed final screenshots separately. Screenshot critique
does not establish behavior, so interactions were checked independently.

## Remaining limits

The existing lazy 3D chunk is about 978KB (263KB gzip) and still triggers Vite's
chunk warning. Physical devices, cross-browser behavior, the full Playwright E2E
suite, perceptual performance, audible feedback, image-error injection and the
actual Waymo/ML/native integration were not exhaustively tested. The scope is UI
coherence; this is not a safety certification. Legacy layout styles remain;
coherence overrides and token tests guard the exercised product surfaces.
